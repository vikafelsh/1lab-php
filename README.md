# PHP CI/CD Project

This repository contains a PHP web application developed as part of a laboratory assignment.

## Project Description
The project demonstrates the development of a PHP application and the implementation of a CI/CD pipeline using GitHub Actions.

## Technologies
- PHP
- Git and GitHub
- GitHub Actions

## Project Goals
- Develop a simple PHP application.
- Use Git for version control.
- Configure automated code checks.
- Implement a CI/CD pipeline.
